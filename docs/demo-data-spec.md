## 4. 核心异常

2026 年 8 月英国 Actual 履约变动成本为 891,643.2815 CNY，Budget 为 317,169.0583 CNY，不利差异为 574,474.2232 CNY。英国订单量由 4,800 单升至 8,932 单；空运包裹占比由 13.69% 升至 66.02%；Carrier C 包裹占比由 2.88% 升至 38.84%。

英国五因素连环替代结果为：

| 因素 |          CNY |
| ---- | -----------: |
| 量   |  85,239.1844 |
| 结构 | 324,207.8221 |
| 效率 |  64,558.2789 |
| 价   |  79,960.1574 |
| 汇率 |  20,508.7803 |
| 合计 | 574,474.2232 |

合计按未舍入高精度值计算；五个已显示到 4 位小数的因素直接相加为 574,474.2231 CNY，0.0001 CNY 为报告舍入尾差，不改变归因恒等式。

结构因素最大、量因素其次，符合冻结的演示故事。管理动作注释明确记录“为维持促销期间履约时效，提高德国仓至英国的空运和 Carrier C 份额”；该因果信息来自注释，不由成本相关性自动推导。

## 5. 全年与情景结果

- 年度 Budget 物流总成本：16,197,761.9712 CNY；
- Latest Outlook 物流总成本：18,327,462.9382 CNY；
- 全年不利差异：2,129,700.9671 CNY；
- Growth Case：英国 9—12 月各月相对正式 Forecast 增加 10%，合计增加 3,398 单和 281,382.5969 CNY 物流总成本；
- Cost Saving Case：9 月准备、10 月部分生效、11—12 月达到目标结构，9—12 月预计减少 168,354.4247 CNY 物流运行成本；
- Cost Saving Case 的 9—12 月预计准时履约率由正式 Forecast 的 96.29% 降至 96.10%，下降约 0.19 个百分点，触发服务软提示但不阻止计算。

Cost Saving 只在现有承运商和有效线路间调整，不引入新供应商，不计入违约金、系统接入、培训或重大流程改造成本。承运能力继续标记为“未验证”；MVP 的无限容量是假设，不是供应商承诺。

## 6. 数值与审计规则

1. Python `Decimal` 使用 80 位计算上下文生成权威高精度结果；正式应用仍按冻结决策使用 TypeScript 单仓库架构和精确十进制计算核心。
2. 原币、币种和汇率均保留；报告币种为 CNY。
3. Actual 权威金额与模型重算金额必须一致；演示数据中的权威差异为零。
4. 连环替代按“量 → 结构 → 效率 → 价 → 汇率”执行；Shapley 使用 32 个组合并回归勾稽。
5. 固定成本不进入五因素归因，也不分摊到目的国、承运商或运输方式。
6. 工作簿使用公式提供审阅层勾稽；高精度权威结果保存在生成 JSON 中，避免 Excel 浮点数成为生产计算权威。
7. 数据生成脚本绑定本次审计工作簿的 SHA-256；来源文件发生变化时必须先重新审计，不能静默生成另一套口径的数据。
