## 1. 验证范围

本报告只验证冻结业务模型，不是 2026 年全年演示数据。夹具包含 2026 年 7 月与 8 月、四条有效履约线路、两个目的国、两个发货仓、三家虚构承运商和两种跨境运输方案。

覆盖内容：

- 六类销售履约变动成本；
- 四类物流运营固定成本；
- 按基础运费比例和按计费重量两种燃油附加费方式；
- EUR、GBP 到 CNY 的折算；
- 量、结构、效率、价、汇率五因素连环替代；
- 32 个因素组合的 Shapley 后台参考；
- 新增和退出线路；
- 原子层下钻与跨月汇总；
- Actual 权威金额不一致阻断；
- 顺序敏感性双重阈值。

## 2. 执行方式

在项目根目录运行：

```powershell
python tests\validate_business_model.py
```

验证器使用 Python `Decimal` 作为独立高精度参考实现，不是未来生产应用的 Python 服务。正式应用仍按 D-044 使用 TypeScript 单仓库全栈架构。

## 3. 结果摘要

### 3.1 2026 年 7 月：纯量变化

| 项目 | CNY |
|---|---:|
| Budget 销售履约变动成本 | 55,094.7714 |
| Actual 销售履约变动成本 | 57,849.5100 |
| 总差异 | 2,754.7386 |

结果：仅订单总量变化时，只有量因素非零。

### 3.2 2026 年 8 月：组合变化

| 项目 | 连环替代 CNY | Shapley CNY |
|---|---:|---:|
| 量因素 | 11,018.9543 | 13,359.3902 |
| 结构因素 | 16,455.9776 | 16,889.9145 |
| 效率因素 | 5,501.3634 | 4,550.3768 |
| 价因素 | 5,815.8557 | 4,422.5532 |
| 汇率因素 | 1,796.1853 | 1,366.1016 |
| 合计 | 40,588.3363 | 40,588.3363 |

Budget 销售履约变动成本为 55,094.7714 CNY，Actual 为 95,683.1077 CNY。两种方法均严格加总到 40,588.3363 CNY 总差异。

固定成本差异为 5,770.0000 CNY，不进入五因素；物流总成本差异为 46,358.3363 CNY。

该组合场景中，连环替代与 Shapley 的单因素差异均未同时达到“归一化差异 10% 且金额达到 Budget 变动成本 0.5%”的提示门槛，因此正式结果不显示顺序敏感警告。独立压力场景已经验证该阈值能够触发。

## 5. 验收结论

小样本证明以下业务模型条件可以同时成立：

1. 六类销售履约变动成本能够由统一确定性公式计算；
2. 固定顺序五因素连环替代严格加总；
3. Shapley 后台参考使用同一成本函数并严格加总；
4. 原子线路归因能够向国家、仓库、承运商、运输方式和公司层一致汇总；
5. 月份作为计算边界时，累计结果等于月度结果之和；
6. 固定成本差异可以与变动成本五因素共同组成物流总成本桥；
7. 显示尾差能够与高精度业务结果分离。

该结论只证明模型结构自洽，不证明虚构参数代表任何真实企业，也不授权生成全年数据或开发正式页面。
