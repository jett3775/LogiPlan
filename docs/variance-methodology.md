# LogiPlan AI 差异归因方法

版本：V1.0  
日期：2026-08-13  
状态：V1.0 已冻结；小样本恒等式验证通过  
权威决策：`docs/decisions.md` D-017 至 D-029  
数据契约：`docs/data-dictionary.md`

## 1. 正式方法

销售履约变动成本使用固定顺序连环替代法，顺序固定为：

```text
量 → 结构 → 效率 → 价 → 汇率
```

正式页面、差异瀑布图和 AI 管理分析均使用连环替代结果。Shapley 分解在后台使用同一成本函数计算，仅用于检查结果对替代顺序是否敏感。

物流运营固定成本不进入五因素模型：

```text
物流总成本差异
= 销售履约变动成本五因素差异
 + 固定成本差异
```

## 2. 比较对象与计算边界

### 2.1 支持的比较

- 单月 Actual 对批准 Budget；
- 单月 Forecast 对批准 Budget；
- 年初至今 Actual 对 Budget；
- 全年最新预测对年度 Budget；
- 任意月份范围的上述结果汇总。

情景相对正式 Forecast 的增量影响使用同一确定性成本函数，但不作为 Budget 五因素正式归因，除非以后明确发布独立情景归因功能。

### 2.2 月份不可跨越

每个月独立执行归因。累计和全年结果只对月度原子归因求和，不先计算年度平均价格、平均汇率或平均结构。

### 2.3 原子层计算、向上汇总

原子键为：

```text
月份 × 目的国 × 发货仓 × 承运商 × 跨境运输方案
```

系统对 Budget 与对比场景的有效线路键并集计算每条线路、每类成本、每个因素的金额。目的国、发货仓、承运商、运输方式和公司层只汇总这些原子结果，不在筛选后重新计算。

因此，下钻层的量因素表示“公司总量变化按 Budget 结构分配到该线路的影响”，不重新定义为该下钻对象自身的量变化。

## 3. 成本函数

### 3.1 业务结构

对某个月，定义：

- `Q`：公司履约订单总量；
- `d[c]`：目的国订单占公司订单的比例；
- `w[c,h]`：目的国订单分配到发货仓的比例；
- `r[c,h,k,m]`：同一目的国与发货仓内，分配到承运商和运输方式的包裹占比；
- `g[line]`：线路单包裹平均计费重量。

各占比满足：

```text
Σc d[c] = 1
对每个目的国 c：Σh w[c,h] = 1
对每个目的国 c、发货仓 h：Σk,m r[c,h,k,m] = 1
```

线路等效订单量为：

```text
equivalent_orders[line]
= Q × d[c] × w[c,h] × r[c,h,k,m]
```

MVP 假设一个订单只属于一个发货仓。仓内可以拆成多个包裹并分配至不同承运商或运输方式，因此线路订单量是可为小数的等效订单量。

### 3.2 效率参数

- `ppo[c,h]`：平均每单包裹数；
- `rr[c]`：退货率；
- `er[line]`：计费异常事件率，即每包裹计费异常事件数。

### 3.3 数量与资源消耗

```text
packages[line]
= equivalent_orders[line] × ppo[c,h]

chargeable_weight[line]
= packages[line] × g[line]

return_packages[line]
= equivalent_orders[line] × rr[c]

billable_events[line]
= packages[line] × er[line]
```

### 3.4 原币价格参数

- `base_rate[line]`：有效每公斤基础运价；
- `fuel_basis[line]`：燃油计费方式；
- `fuel_value[line]`：燃油费率或单位附加费；
- `frontline_variable_labor_price[h]`：有效单均一线作业弹性人工成本；
- `packaging_price[c,h]`：单包裹包装成本；
- `return_price[c,h]`：有效单包裹退货物流成本；
- `exception_price[line]`：平均每计费异常事件成本。

### 3.5 原币成本

```text
base_freight[line]
= chargeable_weight[line] × base_rate[line]
```

燃油附加费按线路价格条件选择一个公式：

```text
fuel[line] = base_freight[line] × fuel_value[line]
  当 fuel_basis = PERCENTAGE_OF_BASE_FREIGHT

fuel[line] = chargeable_weight[line] × fuel_value[line]
  当 fuel_basis = PER_CHARGEABLE_KG

fuel[line] = packages[line] × fuel_value[line]
  当 fuel_basis = PER_PACKAGE（预留）
```

其他成本：

```text
frontline_variable_labor[line]
= equivalent_orders[line] × frontline_variable_labor_price[h]

packaging[line]
= packages[line] × packaging_price[c,h]

return_logistics[line]
= return_packages[line] × return_price[c,h]

billable_exception_cost[line]
= billable_events[line] × exception_price[line]
```

### 3.6 CNY 折算

每个成本类别按其自身原币和适用汇率折算：

```text
cost_cny = original_currency_cost × cny_per_currency_unit
```

同一线路的运输、一线作业弹性人工、包装或退货成本允许使用不同原币。CNY 项目的汇率固定为 1。

销售履约变动成本 `C` 是所有线路、所有六类变动成本的 CNY 金额之和。

## 4. 五个因素的互斥定义

### 4.1 量因素 `Q`

只替换公司履约订单总量。目的国、发货仓、承运商和运输方式分布、重量、效率、价格和汇率保持 Budget。

量因素回答：

> 如果只有公司履约订单总量变化，销售履约变动成本会变化多少？

### 4.2 结构因素 `S`

在实际总量下替换：

- 目的国订单分布 `d`；
- 发货仓订单分布 `w`；
- 仓内承运商和运输方式分布 `r`；
- 单包裹平均计费重量 `g`。

平均每单包裹数不属于结构因素，而属于效率因素。

结构因素回答：

> 在订单总量已确定时，订单流向、履约组合和包裹重量特征变化带来了多少成本差异？

### 4.3 效率因素 `E`

替换：

- 平均每单包裹数 `ppo`；
- 退货率 `rr`；
- 计费异常事件率 `er`。

准时履约率不直接进入成本函数，只用于服务诊断与情景软约束。

效率因素回答：

> 在量和结构已确定时，拆包、退货和计费异常事件频率变化带来了多少成本差异？

### 4.4 价因素 `P`

替换全部原币单位价格与合同计费条件：

- 有效基础运价；
- 燃油计费方式及费率或单位附加费；
- 有效单均一线作业弹性人工成本；
- 包装单价；
- 有效退货物流单价；
- 平均每计费异常事件成本。

同一线路改变燃油计费方式时，完整条件变化归入价因素，不比较不同计费基础下不可比的费率数字。

### 4.5 汇率因素 `X`

最后只替换各原币到 CNY 的汇率。Budget 对 Actual 使用实际月平均会计汇率；Budget 对 Forecast 使用该 Forecast 版本冻结的规划汇率。

原币价格变化在 Budget 汇率下归入价因素；随后折算率变化归入汇率因素。

## 5. 固定顺序连环替代

令成本函数为：

```text
C = F(Q, S, E, P, X)
```

Budget 参数使用下标 `B`，对比场景参数使用下标 `A`。对每个月构造六个状态：

```text
C0 = F(QB, SB, EB, PB, XB)
C1 = F(QA, SB, EB, PB, XB)
C2 = F(QA, SA, EB, PB, XB)
C3 = F(QA, SA, EA, PB, XB)
C4 = F(QA, SA, EA, PA, XB)
C5 = F(QA, SA, EA, PA, XA)
```

正式因素金额：

```text
量因素   = C1 - C0
结构因素 = C2 - C1
效率因素 = C3 - C2
价因素   = C4 - C3
汇率因素 = C5 - C4
```

望远镜求和保证：

```text
量 + 结构 + 效率 + 价 + 汇率
= C5 - C0
= 对比场景销售履约变动成本 - Budget 销售履约变动成本
```

同一公式分别在每条原子线路和每类成本上保存边际差，再向上汇总。

## 6. 新增、退出和零业务量线路

计算底表使用 Budget 与对比场景有效线路键并集。某场景没有业务量时，该线路数量为零，但仍必须从版本化主数据取得反事实所需的：

- 价格条件；
- 平均每单包裹数；
- 退货率；
- 计费异常事件率；
- 汇率；
- 服务参数。

缺少任何必要主数据时，归因校验失败并停止，不填零、不使用市场均价、不产生“未分配差异”。

## 7. Actual 权威金额

Actual 报告成本以发票或已审批预提金额为权威值，确定性模型同时重算金额：

```text
结算差异 = Actual 权威成本 - 模型重算成本
```

MVP 数据要求结算差异为零。存在超过内部精度容差且无法解释的结算差异时，不发布正式五因素归因。这样可确保 `C5` 同时等于模型结果和 Actual 权威报告结果。

## 8. Shapley 后台参考

### 8.1 定义

因素集合：

```text
N = {Q, S, E, P, X}
```

对任意子集 `A ⊆ N`，定义 `v(A)` 为：A 中因素使用对比场景参数，其余因素使用 Budget 参数时的销售履约变动成本。

因素 `i` 的 Shapley 值：

```text
φi = ΣA⊆N\{i}
     |A|! × (|N|-|A|-1)! / |N|!
     × [v(A∪{i}) - v(A)]
```

五个因素共需计算 `2^5 = 32` 个组合。Shapley 也满足：

```text
Σi φi = C5 - C0
```

### 8.2 顺序敏感性提示

对某个报告范围和因素 `i`：

```text
绝对方法差 = |连环替代归因i - Shapley归因i|

归一化方法差
= 绝对方法差 ÷ Σj |Shapley归因j|
```

同时满足以下条件时提示“归因对替代顺序敏感”：

```text
归一化方法差 ≥ 10%

且

绝对方法差 ≥ 该范围 Budget 销售履约变动成本 × 0.5%
```

如果 Shapley 各因素绝对值之和为零，则不存在可评价的因素差异，不显示敏感性提示。

提示只说明因素之间的金额分配受顺序影响；Budget 与对比场景的总成本差异不受方法影响。

## 9. 固定成本差异

固定成本仅按月份、发货仓或共享层、成本类别展示。固定成本类别包括仓租、一线作业基础人工、仓库管理人工和系统费用：

```text
固定成本差异 = 对比场景固定成本 - Budget 固定成本
```

MVP 不把固定成本命名为量、结构、效率或价格因素。非 CNY 固定成本可在后台分拆原币金额变化与汇率变化，但页面默认展示净差异。

后续引入面积、人数、工时和账号量时，扩展独立固定成本驱动子模型，不修改销售履约变动成本五因素定义。一线人员底薪、固定津贴和雇主承担的固定人工不得摊入当期单均变动人工；计件、加班、临时用工及其他量相关人工的单价变化归入价因素。

## 10. 精度、舍入与显示尾差

1. 按数据字典规定的高精度十进制数计算。
2. 原子线路、成本类别和因素结果在汇总前不舍入。
3. 高精度五因素金额必须严格等于高精度总差异。
4. 页面显示到 2 位小数时，可以增加“舍入调整”显示项吸收尾差。
5. “舍入调整”不是第六个业务因素，不写回高精度归因事实。

## 11. 必须通过的小样本测试

| 测试 | 预期 |
|---|---|
| Budget 与对比场景完全相同 | 五因素全部为零 |
| 只有公司订单总量变化 | 仅量因素非零 |
| 只有国家、仓库、承运商、运输方式或重量变化 | 仅结构因素非零 |
| 只有拆包率、退货率或计费异常事件率变化 | 仅效率因素非零 |
| 只有单位价格、燃油费率或燃油计费方式变化 | 仅价因素非零 |
| 只有汇率变化 | 仅汇率因素非零 |
| 全部因素同时变化 | 五因素严格加总；Shapley 同样严格加总 |
| 新增或退出有效线路 | 数量可为零，主数据完整，仍可归因 |
| 跨月份汇总 | 累计因素等于各月对应因素之和 |
| 原子层下钻 | 子项之和等于目的国、仓库和公司层 |
| 固定成本变化 | 不进入五因素；物流总成本桥仍完整 |
| Actual 权威金额与重算不一致 | 阻止正式归因发布 |

## 12. 已知限制

- 连环替代是固定管理口径，不是唯一经济归因或统计因果证明。
- 后置因素会吸收与前序因素的交互影响。
- 有效基础运价综合反映阶梯价和最低收费结果，MVP 不重演包裹级账单规则。
- 平均每计费异常事件成本混合不同异常类型；事件组合变化暂时归入价因素。
- 退货物流单价合并逆向运输和退货处理，无法继续拆分价格来源。
- 一个订单只属于一个发货仓；跨仓拆单留待订单级模型。
- 固定成本没有业务驱动归因；承运商容量也未建模。

## 13. 标准披露文本

> 本分析采用固定顺序连环替代法，按“量、结构、效率、价、汇率”依次替换预算参数。各因素金额严格加总至销售履约变动成本总差异。由于因素之间存在交互影响，部分交互金额会归入顺序靠后的因素，因此结果代表统一管理口径，不代表唯一因果解释。系统同时使用 Shapley 分解检查顺序敏感性，差异达到既定双重阈值时会提示谨慎解释。
