## 4. 执行模型、验证与停点

用户指定 **DeepSeek v4.1 Flash** 用于开发执行，这不是产品 LLM 供应商变更，也不自动修改 AGENTS 配置。采用“一次一个阶段、先复述范围与不变量、小步实现后定向测试”的方式；这是规划假设，不是能力评分。无法确认实际使用模型时必须写未知，不能标称已由 DeepSeek 执行。

未来代码工作为 **L2**：同一 owner 连续实现与自测，独立 auditor 审查；问题返回原 owner，再由原 auditor 复查。两轮仍失败必须停止。运行者记录与仓库首选模型的配置偏差，不降低验证要求。

本次文档同步为 **L1**。文档实现首选 `gpt-5.6-terra / medium` 未在运行环境可用列表中提供，按 [工作流 §2.6](multi-agent-workflow.md) 使用环境默认模型；实际精确 ID 与推理强度未暴露，记为未知。该偏差发生在文档实现环节。

- 定向入口：`pnpm exec vitest run packages/ai/src/control-plane/server.test.ts packages/ai/src/read-monthly-usage.test.ts`。
- 必需矩阵：`pnpm test`、`pnpm typecheck`、`pnpm lint`、`pnpm format:check`、`pnpm build`；Web 追加无增量类型检查，命令见当前计划。
- 覆盖率：先保留 `pnpm test:coverage` 既有门槛，再对 AI 包全部测试做独立测量。AI 当前不在默认 `coverage.include`，没有该包专属阈值；不能把“测到数值”写成“达标”。
- 本日不改页面/数据库，不机械追加相应专项；若影响扩展先重评。合并、部署或阶段闸门前仍需完整 Playwright、性能和可访问性等额外验收。
- `pnpm --filter @logiplan/ai run usage` 会自动加载根 `.env`，不作为本日无外部影响的验证命令。使用 Vitest 替身，不打印配置值。
- 必需检查失败、阻断或未执行就保留未完成状态；不能以历史 CI、受控失败或固定示例代替。遇工具保护不得关闭；构建需用户终端补验时记录准确命令与欠缺证据。
